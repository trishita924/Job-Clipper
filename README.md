# Job Clipper — Job & Internship Application Tracker

A smart, local-first Chrome and Brave extension to save job and internship listings, track applications, manage deadlines, and export your application data.

## 🚀 Quick Links

### 📦 [Download Job Clipper Extension (ZIP)](https://github.com/trishita924/Job-Clipper/archive/refs/heads/main.zip)

### 💻 [View GitHub Repository](https://github.com/trishita924/Job-Clipper)

## ✨ Features

- **One-Click Job Clipping:** Save job listings with automatically detected details.
- **Editable Job Details:** Edit job title, company, URL, deadline, location and notes.
- **Application Tracking Board:** Organize applications into Saved, Applied, Interview and Result.
- **Drag & Drop:** Move job cards between application stages.
- **Deadline Reminders:** Receive desktop notifications before application deadlines.
- **Search & Filters:** Find applications quickly.

# Job Clipper — Job & Internship Application Tracker

A smart, local-first Chrome and Brave extension to save job and internship listings, track applications, manage deadlines, and export application data.

## 🚀 Quick Links

### 📦 [Download Job Clipper Extension (ZIP)](https://github.com/trishita924/Job-Clipper/archive/refs/heads/main.zip)

### 🧩 [Open Brave Extensions](brave://extensions/)

## ✨ Features

- **One-Click Job Clipping:** Save job listings with automatically detected details.
- **Editable Job Details:** Edit job title, company, URL, deadline, location and notes.
- **Application Tracking Board:** Organize applications into Saved, Applied, Interview and Result.
- **Drag & Drop:** Move job cards between application stages.
- **Deadline Reminders:** Receive desktop notifications before deadlines.
- **Search & Filters:** Find applications quickly.
- **CSV Export:** Export application records for Excel and Google Sheets.
- **Local Storage:** Your application data stays stored locally in your browser.

## 🛠️ Technology Used

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3
- Chrome Storage API
- Chrome Alarms API
- Chrome Notifications API

## 📥 Installation Guide

1. Click **Download Job Clipper Extension (ZIP)**.
2. Extract the downloaded ZIP file.
3. Click **Open Brave Extensions** above, or type `brave://extensions/` in your browser.
4. Enable **Developer Mode**.
5. Click **Load unpacked**.
6. Select the extracted `Job-Clipper` folder containing `manifest.json`.
7. Pin Job Clipper to your browser toolbar.
8. Open the extension and start tracking your applications!

## 🔒 Privacy

Job Clipper uses local browser storage. It does not require an account, backend server, or external database.
